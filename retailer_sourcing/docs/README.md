# retailer_sourcing — Documentation

## Overview
retailer_sourcing is a Rust library that provides tooling for retailer sourcing workflows: catalogue, collection, crawl, scheduling, and shared types. This documentation area will host user-facing guides and developer notes.

## Getting started
- Prerequisites: Rust toolchain (rustup, cargo)
- Build: `cargo build --manifest-path retailer_sourcing/Cargo.toml`
- Test: `cargo test --manifest-path retailer_sourcing/Cargo.toml`

## Module map
- app — application-level entry points and configuration
- crates — domain modules
  - catalogue
  - collection
  - crawl
  - scheduling
  - types
